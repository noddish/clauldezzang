EMBERCRYPT / 잿불 묘지 — v0.6 Ash Marks · 재의 흔적

실행
1. Godot 4.6.3 Standard에서 project.godot를 가져옵니다.
2. 첫 에셋 임포트가 끝나면 F5를 누릅니다.
3. F2 또는 메뉴 → 설정 → 가로·세로 전환으로 배치를 비교합니다.
4. PREVIEW.html에서 실제 실행 화면과 전환 영상을 확인합니다.

이번 버전
고정 하단 띠와 반복되는 카드 배경을 제거하고 던전을 화면 전체에 렌더링합니다.
배경 없는 얼굴 옆의 붉은 세로선과 숫자는 HP, 선택 영웅 아래 청록 룬은 MP입니다.
공격은 큰 검, 스킬은 영웅의 역할에 맞는 표식, 전술은 붉은 흔적으로 표시됩니다.
적의 HP는 적 가까이에 붙고, 지도는 장면 위에 경로선으로 펼쳐집니다.
메뉴를 열면 기본 HUD를 숨겨 상세 내용과 겹치지 않게 합니다.
기존 던전·캐릭터 아트와 게임 규칙은 유지했습니다.

탐험
던전 빈 영역을 위/아래로 밀어 전진/후진, 좌/우로 밀어 회전합니다.
화면 아래 '이동'을 누르면 횡이동을 포함한 여섯 방향 표식이 펼쳐집니다.
조사 표시가 뜬 열쇠·문·적·상자를 직접 누르거나 오른쪽 조사 아이콘을 사용합니다.
지도·메뉴는 상단, 원정대는 초상화와 '원정대' 라벨에서 엽니다.

전투
초상화로 영웅 선택 → 공격 또는 스킬. 전술에서 방어·아이템을 엽니다.
적 탭은 선택, 적을 길게 누르면 설명. 적 옆 HP·정보 표식도 누를 수 있습니다.
스킬을 길게 누르면 효과와 비용만 설명하며 손을 떼도 실행하지 않습니다.
물약: 가방 → 물약 → 회복할 동료 → 사용. 아이콘을 잠시 누르고 동료로 끌어도 사용됩니다.
행동 연출 중에는 추가 행동이 잠깁니다. HP와 반격 기록은 실제 타격 시점에 표시됩니다.

상세 화면
가로는 오른쪽, 세로는 아래에서 내용이 나타납니다.
지도·가방·원정대는 각각 다른 형태지만 닫기와 뒤로가기 조작은 같습니다.
× 또는 바깥 탭으로 닫고, ‹ / Esc로 이전 화면에 돌아갑니다.
세로 가방은 손잡이를 위로 밀거나 '가방 펼치기'를 눌러 확장합니다.
지도: 핀치 확대, 드래그 이동, 두 번 탭으로 초기화. +/−/위치 맞춤도 있습니다.
목표·전투 기록: 상단 위치를 누르거나 메뉴 → 목표·기록.
설정: 소리, 모션 줄이기, 진동, 이동 버튼 고정, 새 탐험.

PC
W/S 또는 ↑/↓ 전진·후진 / A/D 또는 ←/→ 회전 / Q/E 횡이동
Space/Enter 조사 / 1~4 영웅 / J 공격 / K 스킬 / G 방어 / H 물약
M 지도 / F1 조작 안내 / F2 방향 비교 / Esc 뒤로가기·메뉴
마우스 클릭·드래그·길게 누르기·행동 위 호버 설명도 지원합니다.
작게 보이는 아이콘에도 최소 48×48 논리 픽셀의 터치 영역이 있습니다.

첫 원정 (약 3~5분)
입구에서 전진 → 동쪽 벽감에서 열쇠 획득 → 중앙 북쪽 문 열기
→ 경비병과 전투 → 북쪽 끝 상자에서 봉인과 금화 회수.
아린: 21 피해/MP4, 로언: 20 피해/MP4, 이든: 28 피해/MP6,
세라: 살아 있는 동료 전원 HP14 회복/MP5.
방어: 반격 피해3·MP3 회복. 물약: 한 명 HP25 회복.

저장
행동·포커스 변경 후 자동 저장. expedition-v1.json 형식은 이전 버전과 같습니다.
UI 설정은 mobile-ui.cfg에 저장됩니다. 새 탐험은 확인 후 진행을 초기화합니다.
테스트와 캡처의 --fresh는 기존 저장과 설정을 읽거나 덮어쓰지 않습니다.
