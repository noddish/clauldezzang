# 초크네임 (가제) — 게임 기획서 v0.4

## 한 줄 소개

고아 '나인'이 가장 낮은 E랭크 모험가로 시작해 위로 올라가면서, 지도에서 사라진 자기 고향을 찾는 판타지 RPG.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 파티 RPG |
| 파티 | 주인공 + 동료 3명 |
| 진행 | 랭크가 오를수록 갈 수 있는 지역이 늘어난다 |
| 분량 | 메인 스토리 약 30시간 |
| 분위기 | 가난한 신참 모험가의 고생담 + 출신의 비밀 |

## 핵심 재미 3가지

1. **밑바닥부터 올라가기:** E랭크 잡일부터 시작해서 S랭크를 향해 간다.
2. **내 고향 찾기:** 어릴 때부터 부르던 자장가의 가사를 모아서 사라진 고향으로 가는 길을 찾는다.
3. **개성 있는 동료:** 동료마다 판단 기준이 달라서, 같은 선택에도 반응이 다르다.

## 원작 『나의 악당들』에서 참고한 점

이야기와 인물은 가져오지 않았습니다. 재미를 만드는 방식만 참고했습니다.

| 원작에서 좋았던 점 | 이 게임에서는 |
|---|---|
| 정체를 바로 알려주지 않고 하나씩 알아가게 한다 | 처음 보는 적은 '???'로 나온다. 관찰하면 정보가 열린다 |
| 전투에서 왜 이겼는지, 왜 졌는지가 보인다 | 장비마다 장단점이 있고, 지형이 전투에 영향을 준다 |
| 상처가 오래 남고 생활에 영향을 준다 | 주인공도 재생하지 않는다. 큰 부상은 은퇴로 이어질 수 있다 |
| 설정이 생활 속에서 보인다 | 돈, 숙소, 치료비 같은 생활 요소가 있다 |
| 인물마다 판단 기준이 다르다 | 동료마다 기준이 하나씩 있고, 선택에 다르게 반응한다 |
| 첫인상과 실제가 다르다 | 동료마다 겉보기와 진짜 특기가 다르다 |

## 원작과 겹치지 않게 뺀 것

- 미래를 아는 주인공 (빙의, 회귀, 예언서)
- '악당'을 동료로 모으는 구조
- 영주가 되어 영지를 키우는 전개, 전쟁 정치
- 봉쇄된 항구와 해적 습격으로 시작하는 전개
- 재생하는 주인공
- 주인공의 숨겨진 고귀한 혈통
