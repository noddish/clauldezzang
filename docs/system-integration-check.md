# 시스템 연계 점검 — 지금 엔진으로 '장사 + 던전 + 사람' 을 만들 수 있나

> 2026-11-20. `mosshill/game` 코드를 직접 열어 확인했다.
> 표시: **그대로** = 손대지 않고 씀 / **넓히기** = 구조는 맞고 기능만 더함 / **손볼 것** = 지금 구조가 새 설계와 부딪힘

## 1. 기술 점검 (시스템별)

| 시스템 | 파일 | 판정 | 내용 |
|---|---|---|---|
| 퀘스트 상태 머신 | core/quest.rpy | 그대로 | 단계·트리거·잠 지연. 단계를 이름으로 저장해 세이브에 강함 |
| 이벤트 등록부 | core/events.rpy | 그대로 (+넓히기) | 장소 진입·메인 루프 이벤트. **이동 중 사건**(on="travel"), 아침 시작 사건을 추가하면 됨 |
| 잠김 규칙 | core/locks.rpy | 그대로 | (출발, 도착) 규칙 + 짧은 이유. 경로 잠김에도 그대로 씀 |
| 신뢰도 | core/bond.rpy | 그대로 (+넓히기) | 인물별 수치. 친해지면 기능이 열리게(할인·소문) 연결만 추가 |
| 데이터(JSON) | core/data.rpy | 넓히기 | 파일 목록에 교역품·도시·경로·용병 추가, 서로 가리키는 id 검사도 추가 |
| 전투 계산 | python-packages/mhrpg/battle.py | 그대로 | 아군 수 제한 없음(목록). 어디서든 `call battle(구역)` |
| 전투 화면 | rpg/battle.rpy | 넓히기 | 배경을 `location_bg(here)` 로 고정 → **길 위 전투는 배경을 따로 받아야 함**. 졌을 때 '골드 반, HP 반' 은 길 위에서는 '짐 일부 잃기' 로 따로 |
| 시간 | core/time.rpy | **손볼 것** | 하루 4칸은 그대로. 그러나 ① `tick()` 은 밤에서 멈추고 침대에서 자야 다음 날 → **며칠 걸리는 이동**과 부딪힘 ② 잠자면 파티가 전부 회복(SLEEP_HOOKS) → 길 위 야영은 다른 규칙 필요 ③ `LAST_DAY=3`, 요일 없음(`is_weekend()` 가 항상 False) → 달력(요일·계절) 필요 |
| 장소 | core/location.rpy | 넓히기 | 장소 트리·물건·조각·장식 그대로. **도시가 여럿**이면 도시마다 지도 뿌리 + 도시 사이 경로 지도를 더함. 장소 id 에 도시 이름을 붙일 것 (`mosshill_tavern`). '길 위' 는 장소가 아니라 이동 상태 |
| 인물 위치표 | core/quest.rpy `where()` | 넓히기 | [평일/주말][시간대] 표 → 요일·날짜·함수로도 정할 수 있게 (다른 도시를 오가는 상인 등) |
| 파티 | rpg/party.rpy, mhrpg/stats.py | **손볼 것** | 파티가 `["player", "ruby"]` 로 고정, 성장표(levels.json)가 **인물 이름별** → 용병처럼 같은 직업을 여럿 고용하려면 **직업별 성장표** + 파티원 정보에 직업·이름·임금·특성, 그리고 '보유 인원(로스터)'과 '데려가는 파티(최대 4)' 구분이 필요 |
| 소지품 | rpg/inventory.rpy | **손볼 것** | 모든 물건이 한 주머니, 무게·용량 없음 → **개인 가방**(장비·소모품·중요품)과 **마차 짐칸**(교역품, 무게 한도)으로 나눔. 던전 재료는 가방에 들어오고 짐칸으로 옮겨 팔게 |
| 상점 | rpg/shop.rpy | 넓히기 | 정해진 값 × 되팔기 50%. 장비·소모품 가게는 그대로 두고, 교역품은 **시세가 움직이는 시장**을 따로 만듦. 던전 재료를 정가 가게에서 팔 수 있으면 무한 돈벌이가 되므로 시장에서만 |
| HUD | ui/hud.rpy | 넓히기 | 시간·골드·퀘스트 그대로. 짐칸(무게)·현재 도시 표시 추가 |
| 자동 검사·자동 플레이 | dev/ | 넓히기 | 사고팔기·이동 단계 추가 |
| 밸런스 시뮬레이터 | tools/balance_sim.py | 넓히기 | 전투만 → 돈이 들어오고 나가는 흐름(장사 이익, 던전 수입, 임금·유지비)도 시뮬레이션 |
| 세이브 | — | 넓히기 | 지금은 store 변수라 안전. 본편 업데이트를 대비해 세이브 버전 번호 추가 |

**정리:** 그대로 쓰는 것 6, 기능만 더하는 것 9, 손볼 것 3 (시간, 파티, 소지품).
손볼 3가지도 다시 만드는 게 아니라 구조를 넓히는 일이다 — 지금 루비·카이는 '직업이 정해진 파티원' 으로 그대로 옮겨진다.

## 2. 설계 점검 — 세 가지가 서로 방해하는 곳과 해결책

| 부딪힘 | 왜 문제인가 | 해결 |
|---|---|---|
| **시간 쟁탈** | 장사 이동이 며칠씩 걸리면 던전·사람 만날 시간이 없음. 카이가 없는 동안 고향 인물 이야기가 멈춤 | 가까운 도시는 반나절~하루. 던전은 거점 가까이. 다른 도시에도 인물과 이야기. 이야기 마감은 넉넉히. 이동 중에는 동료와 대화 (사람 기둥을 길 위로도) |
| **돈 경쟁** | 던전 수입과 장사 이익 중 하나가 압도하면 다른 하나를 안 함 (마운트 앤 블레이드) | 던전은 주로 **재료**(돈이 아니라)를 주고, 재료는 시장(팔수록 값이 떨어짐)에서 돈이 되거나 강화에 쓰임. 장사는 돈. 돈 나갈 곳(임금, 마차 유지비, 통행료, 강화)을 두어 돈이 늘 의미 있게 |
| **전투 중복** | 던전 전투와 길 위 전투가 똑같으면 금방 질림 | 같은 전투 엔진, 다른 성격: 길 위는 드물게·짧게, '통행료를 낼까 싸울까 달아날까', 마차를 지키기. 던전은 탐험·보스·전리품 |
| **동료 대 용병** | 이야기 동료와 고용 용병이 파티 자리를 다툼. 용병이 소모품처럼 느껴짐 (다키스트 던전) | 이야기 동료는 소수. 용병은 주로 **마차 호위**(나중엔 두 번째 마차에 붙여 보냄)와 빈자리 채우기 |
| **사람 기둥이 뒷전** | 바쁘게 장사·던전만 하면 관계는 건너뛰게 됨 | 친해지면 **기능**이 열림(할인, 소문, 새 물건, 새 의뢰). 인물의 부탁은 장사·던전에서 얻는 물건이 필요 (스타듀 꾸러미처럼) → 세 기둥을 한데 묶음 |
| **회복 규칙** | 집에서 자면 전부 회복 → 길 위도 같으면 이동에 긴장이 없음 | 길 위는 야영: 식량을 쓰고 일부만 회복 |
| **패배 규칙** | 지금은 '골드 반' 하나뿐 | 던전에서 지면 마을로 실려 옴(돈 일부), 길 위에서 지면 짐 일부를 잃음. 게임 오버는 없음 |

## 3. 순서 제안 (만들 때)

1. 손볼 3가지 먼저: 시간(달력·여러 날 이동·야영), 파티(직업별 성장·로스터), 소지품(가방·짐칸)
2. 시장 시세 엔진 (순수 파이썬, 시뮬레이터로 검사)
3. 도시·경로 데이터 + 경로 지도 + 이동 중 사건
4. 사람 기둥 연결 (신뢰도 → 기능, 부탁 = 물건)
