# 모스힐 세계 설계 (장소·인물 배치)

> 사용자와 한 단계씩 같이 정한다. 정한 것은 **확정**, 제안만 한 것은 **제안**으로 표시한다.
> 맛보기판(첫 30분)은 이 설계의 일부만 쓰지만, 지도·장소 구조는 본편 전체를 기준으로 만든다.

## 진행 순서

1. 마을의 큰 그림 — 어떤 곳인지, 주변 지형
2. 장소를 한 곳씩 — 이름, 하는 일, 언제부터 갈 수 있는지, 안의 방, 지도 위 위치
3. 인물을 한 명씩 — 언제(아침/오후/저녁/밤) 어디에서 무엇을 하는지
4. 정한 대로 지도(바닥 지도 + 장소 조각)와 장소 그림 만들기

## 지도 방식 (확정)

- PC: 한 화면에 다 보이게. 장소가 늘어 화면을 넘으면 끌어서 이동.
- 모바일: 끌어서 이동 + 두 손가락 확대·축소.
- 구조: 바닥 지도 + 장소마다 건물 조각 (원작 방식). 잠긴 곳은 흐리게, 마우스를 올리면 이유.

## 1. 마을의 큰 그림

- **확정:** 모스힐은 **모험가가 많이 지나가는 도시**다.
- **확정:** 모험가가 지나가는 이유는 **둘 다** — 왕도와 여러 지역을 잇는 큰길이 지나가고, 도시 근처에 던전(숲·이끼 동굴 등)도 있다.
- **확정:** **모험가 길드는 전국 조직**이고, 모스힐에는 그 **지부**가 있다. (예전 설정의 독립 길드 '이끼발굽 길드'와 '왕도 모험가 협회'는 이 구조로 바꾼다.)
- **확정:** 기존 인물(루비·마르타·핍·그레고르)의 **직업과 있는 장소도 다시 정한다** (3단계).
- 지금 있는 장소(길드하우스, 선술집 '졸린 곰', 핍의 잡화점, 광장, 숲길 → 이끼 동굴)도 위 결정에 맞춰 다시 본다.
- **정할 것:**
  - 카이는 지부에서 어떤 사람인가 (새 지부장 / 신참 모험가 / 지부 직원 …)
  - 지부는 지금 어떤 상황인가 — 맛보기판의 '3일 뒤 감사' 이야기와 이어진다
